# 📚 My Library Dashboard

## 📝 Description

My Library Dashboard is a simple and responsive library management website built as a web development project.

The dashboard allows users to view books, search for books, navigate through different library sections, and manage library information.

## ✨ Features

* 📚 Library dashboard
* 🔍 Search books
* 📖 View all books
* 👥 View library members
* 📱 Responsive sidebar
* ☰ Open and close menu
* 💻 Simple and user-friendly interface

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` with Live Server.
4. View the website in your browser.
